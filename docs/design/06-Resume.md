# 06 - Resume

## Goal

Redesign only resume management. Preserve upload, replace, download, preview, metadata, and validation behavior.

## Resume Upload

Use a polished upload dropzone with accepted file types, max size, progress, and validation.

## Resume Preview

Show preview panel if available. Use fallback empty state if not.

## Resume History

Show versions with upload date, file type, size, and action.

## ATS Score

Show score or readiness state. Do not fake AI output.

## Suggestions

Show missing sections, keywords, formatting tips, and profile links if data exists.

## Download

Download action should be clear and disabled when no resume exists.

## Responsive

Mobile stacks upload, preview, and history. Desktop uses two-column layout.

## Prompt For Stitch

Read `00-DesignSystem.md` then redesign ONLY Resume. Preserve existing resume upload and file workflows.
