## Scheduled Tasks

Expire jobs, archive jobs, publish scheduled content, refresh recommendations, refresh SEO, refresh search index, refresh salary data, send reminders, renew subscriptions, cleanup drafts, and aggregate analytics.

## Observability

Important events must include correlation IDs and be logged across user, employer, admin, CMS, marketplace, automation, recruitment, payments, search, storage, and API domains.
