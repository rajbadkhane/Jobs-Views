# 08 - Saved Jobs

## Goal

Redesign only saved jobs. Preserve save, remove, collections, notes, archive, search, and filters.

## Collections

Use folder-like collections with counts and recent activity.

## Notes

Show notes inline or in drawer.

## Archive

Archive/remove action should be clear and recoverable where supported.

## Search

Search saved jobs by title, company, skill, and location.

## Filters

Filter by collection, date saved, job type, status.

## Responsive

Mobile single-column cards. Desktop grid/list toggle if existing.

## Prompt For Stitch

Read `00-DesignSystem.md` then redesign ONLY Saved Jobs. Preserve saved job workflows.
