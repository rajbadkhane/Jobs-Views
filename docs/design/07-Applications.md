# 07 - Applications

## Goal

Redesign only candidate applications. Preserve application statuses, withdraw, timeline, interview, offer, and history workflows.

## Timeline

Show application events with status, message, actor if available, and timestamp.

## Status

Use semantic status badges and progress indicators.

## Withdraw

Withdraw action must be clear, confirm if destructive, and update status.

## Interview

Show interview details, mode, date, meeting link, and feedback state.

## Offer

Show offer status, salary, joining date, position, download action if available.

## History

Show full application history in timeline/list.

## Filters

Filter by status, company, date, and keyword.

## Search

Search applications by job/company.

## Responsive

Mobile cards; desktop table/list with detail panel.

## Prompt For Stitch

Read `00-DesignSystem.md` then redesign ONLY Applications. Preserve all candidate application workflows.
