# Storage Architecture

## Storage Providers

- Local
- Cloudflare R2
- S3 placeholder
- Azure Blob placeholder
- Google Cloud Storage placeholder

## Supported Assets

- Avatar
- Resume
- Company logo
- Banner
- Gallery
- Certificates
- Offer letters
- Verification documents

## Requirements

Storage adapters must support upload, download, replace, delete, validation metadata, and signed URL readiness.
