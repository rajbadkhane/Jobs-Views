# 18 - Admin Dashboard

## Goal

Redesign only admin dashboard. Preserve platform overview, quick actions, monitoring, support, and analytics.

## Platform Overview

Show users, companies, jobs, applications, revenue, plans, support, system health.

## Users

Show user growth and active users.

## Companies

Show verification and company status.

## Jobs

Show active jobs and moderation queue.

## Applications

Show application totals and funnel.

## Revenue

Show revenue/MRR/ARR where available.

## Monitoring

Show API, database, Redis, storage, queue.

## Support

Show tickets and priority.

## Quick Actions

Create admin, approve company, approve jobs, publish CMS, broadcast.

## Responsive

Mobile prioritizes KPIs, queues, system health.
