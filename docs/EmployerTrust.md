# Employer Trust

## Company Verification Score

Company verification score uses:

- Verification completion
- Response rate
- Hiring speed
- Offer acceptance
- Candidate rating placeholder
- Profile completion

## Employer Careers Site

Each employer careers site remains mapped to `/companies/[slug]` and can display:

- About
- Culture
- Benefits
- Open jobs
- Gallery
- Locations
- Hiring process

## Hiring Dashboard

Employer dashboard widgets cover:

- Today's interviews
- Today's joining
- Offers pending
- Documents pending
- Candidates nearby
- Urgent jobs
- Recruiter tasks
