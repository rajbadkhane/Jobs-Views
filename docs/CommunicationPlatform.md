# Communication Platform

## Purpose

All Jobs View communication should pass through one adapter-based engine. The engine supports email, SMS, push, WhatsApp placeholder, in-app, browser notifications, and future voice placeholders.

## Events

Supported events include candidate registration, employer registration, email verification, password reset, application updates, interview events, offers, joining reminders, employer approval/rejection, subscription/payment events, and admin announcements.

## Requirements

- Templates
- Variables
- Localization readiness
- Retry queue
- Logging
- Delivery status
- Open tracking placeholder
- Vendor-neutral adapters
