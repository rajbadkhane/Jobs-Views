# 04 - Candidate Dashboard

## Goal

Redesign only the candidate dashboard. Preserve all candidate data, actions, routes, and workflows.

## Greeting

Show candidate name, profile context, and next-best action.

## Profile Strength

Use progress visualization, missing fields, and clear update action.

## Career Health

Show score, summary, and recommended improvement areas.

## Resume Score

Show resume uploaded/missing state, ATS readiness, upload/replace action.

## Recommended Jobs

Use job cards with apply, save, and share actions.

## Applications

Show status summary and recent application list.

## Notifications

Show unread notifications and quick actions.

## Timeline

Show application and profile activity.

## Quick Actions

Include update resume, edit profile, browse jobs, saved jobs.

## Charts

Use simple progress and trend charts. Avoid clutter.

## Calendar

Show upcoming interviews if available.

## Responsive

Mobile: summary first, then jobs, applications, resume. Desktop: KPI grid and content columns.

## Dark Mode

Ensure charts, progress, cards, and badges remain readable.

## Prompt For Stitch

Read `00-DesignSystem.md` then redesign ONLY Candidate Dashboard. Preserve every dashboard widget and action.
