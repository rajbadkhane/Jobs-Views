# 09 - Employer Dashboard

## Goal

Redesign only employer dashboard. Preserve company context, job stats, applications, analytics, notifications, and quick actions.

## Greeting

Show company/workspace greeting and verification status.

## Hiring Summary

Show active jobs, draft jobs, published jobs, closed jobs, applications, interviews, offers, hires.

## KPI Cards

Use clear KPI cards with icons, values, deltas, and links.

## Hiring Funnel

Show funnel chart based on pipeline statuses.

## Charts

Use Recharts for trends, sources, job performance.

## Recent Applications

Show latest candidates with status and quick view.

## Calendar

Show interviews and upcoming hiring events.

## Notifications

Show unread hiring alerts.

## Quick Actions

Create job, invite member, view pipeline, open analytics.

## Responsive

Mobile prioritizes company status, KPIs, recent applications, quick actions.

## Prompt For Stitch

Read `00-DesignSystem.md` then redesign ONLY Employer Dashboard. Preserve existing employer workflows.
