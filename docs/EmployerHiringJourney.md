# Employer Hiring Journey

## Flow

1. Employer creates a job.
2. Jobs View calculates matching candidates through the intelligent matching engine.
3. Employer sees matching candidates, nearby candidates, freshers, experienced candidates, and top skill clusters.
4. Employer can invite, shortlist, message, schedule interviews, create offers, and track response quality.
5. Hiring analytics track funnel, response rate, hiring time, source analysis, recommendation accuracy, and hiring cost placeholder.

## Status

Shared analytics and matching functions are implemented. Persistence is ready for recommendation events, candidate views, and conversations.
