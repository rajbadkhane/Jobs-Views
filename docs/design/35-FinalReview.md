# 35 - Final Review

## Goal

Final design checklist before Stitch output is approved for Codex implementation.

## Checklist

- Premium SaaS quality.
- Consistent with `00-DesignSystem.md`.
- Preserves functionality.
- Preserves API flow.
- Preserves routing.
- Preserves RBAC.
- Preserves workflows.
- Responsive across mobile, tablet, desktop, ultra-wide.
- Dark mode complete.
- Light mode complete.
- Accessible and WCAG AA ready.
- Clear focus states.
- Keyboard navigable.
- Loading states designed.
- Empty states designed.
- Error states designed.
- Animation is lightweight.
- Performance conscious.
- SEO ready for public pages.
- Tables and forms production-grade.
- Components are reusable.
- Visual hierarchy is clear.
- Whitespace is intentional.
- Typography is consistent.
- Screenshot worthy.
- Launch ready.

## Prompt For Stitch

Before final approval, review the generated design against this checklist. If any item fails, revise the UI/UX without changing business logic.
