# 05 - Candidate Profile

## Goal

Redesign only candidate profile management. Preserve profile fields, update actions, upload actions, validation, and route behavior.

## Personal

Show name, title, phone, location, availability, avatar, and public profile state.

## Education

Use editable list/card rows with qualification, university, dates, and certificate if present.

## Experience

Show current and previous roles, company, dates, achievements, and actions.

## Projects

Show project cards with links and descriptions.

## Skills

Use grouped skills with category, level, and years of experience.

## Languages

Show proficiency badges.

## Certificates

Show certificate cards with issuer and file/link.

## Portfolio

Show LinkedIn, GitHub, portfolio, website, and social links.

## Resume

Show resume upload/replace/download state.

## Settings

Include privacy and visibility controls where existing.

## Loading

Use profile skeleton sections.

## Accessibility

Forms need labels, helper text, validation, and keyboard flow.

## Prompt For Stitch

Read `00-DesignSystem.md` then redesign ONLY Candidate Profile. Preserve all profile modules and actions.
