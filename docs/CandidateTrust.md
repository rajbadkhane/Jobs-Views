# Candidate Trust

## Inputs

Candidate trust score uses:

- Profile completion
- Verified documents
- Interview attendance
- Offer acceptance
- Resume quality
- Employer feedback placeholder

## Digital Profile Card

Each candidate can be represented by:

- Unique Jobs View ID
- QR payload
- Public profile URL
- Verified badge
- Resume preview
- Skills
- Experience
- Languages
- Availability

## Document Signals

Verified Aadhaar, PAN, driving license, police verification, medical fitness, education certificates, and experience certificates increase workforce readiness.
