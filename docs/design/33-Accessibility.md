# 33 - Accessibility

## Goal

Define WCAG AA accessibility rules for Jobs View.

## WCAG AA

All screens must target WCAG AA.

## Keyboard

Every interactive element must be keyboard accessible.

## ARIA

Use ARIA only when semantic HTML is insufficient. Icon-only buttons need accessible labels.

## Contrast

Text, badges, buttons, charts, focus rings must meet contrast requirements.

## Focus

Visible focus ring on all controls.

## Screen Reader

Use semantic headings, labels, table headers, live regions where needed.

## Prompt For Stitch

Read `00-DesignSystem.md` then apply these accessibility rules to every generated screen.
