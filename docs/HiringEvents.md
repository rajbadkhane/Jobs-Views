# Hiring Events

## Supported Event Types

- Walk-in drives
- Campus drives
- Mass hiring
- Job fairs
- Security guard drives
- Delivery drives
- Factory drives

## Event Model

Events include:

- Location
- Date
- Capacity
- Eligible roles
- Documents required
- Registrations
- Attendance
- Selected candidates

## Metrics

The workforce engine calculates registration rate, attendance rate, and selection rate for every event.
