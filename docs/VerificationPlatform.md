# Verification Platform

## Verification Types

- Email
- Phone
- Government ID
- Education
- Experience
- Employer
- Police verification
- Driving license
- Medical

## Statuses

- Missing
- Pending
- Verified
- Rejected
- Expired

## Document Vault

Documents support expiry, verification, download, replace, history, and admin verification flags. The shared contract includes Aadhaar, PAN, driving license, passport, resume, certificates, police verification, medical fitness, vaccination, bank details, UAN, ESIC, and PF.
