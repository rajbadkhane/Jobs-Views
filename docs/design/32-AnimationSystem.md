# 32 - Animation System

## Goal

Define Jobs View motion rules for Framer Motion.

## Framer Motion

Use lightweight transitions. Respect reduced motion.

## Hover

Small lift or color change only.

## Buttons

150ms hover/focus transition.

## Cards

Actionable cards lift -1px to -2px.

## Sidebar

Slide/fade with 200ms transition.

## Dialogs

Fade and scale 0.98 to 1.

## Dropdown

Fade and translate 4px.

## Charts

Animate initial render only.

## Timeline

Subtle stagger allowed.

## Page Transition

Use only if it does not delay usability.

## Loading

Skeleton pulse, progress bars.

## Reduced Motion

Disable layout movement and keep opacity changes minimal.

## Prompt For Stitch

Read `00-DesignSystem.md` then apply this animation system. Never over-animate.
