# 28 - Authentication

## Goal

Redesign only authentication UI. Preserve login, register, forgot password, reset password, verify email, employer registration, candidate registration, redirects, and RBAC.

## Login

Email/password form, remember me, validation, loading, error.

## Register

Role-aware candidate/employer registration.

## Forgot Password

Simple email form with success state.

## Reset Password

Token and new password form.

## Verify Email

Token verification state.

## Employer Registration

Company fields, website, GST, CIN, pending state.

## Candidate Registration

Name, email, mobile, password, profile creation state.

## Responsive

Mobile centered form with full-width actions.
