# 12 - ATS Pipeline

## Goal

Redesign only ATS pipeline. Preserve statuses, status updates, candidate details, notes, ratings, tags, interviews, offers, reject, hire, and bulk actions.

## Kanban

Columns follow existing application statuses. Keep columns scannable and horizontally scrollable on desktop.

## Drag Drop

Design drag-ready states without changing backend behavior.

## Candidate Card

Show name, job, stage, rating, tags, last activity, quick actions.

## Notes

Show notes indicator and detail drawer.

## Ratings

Use accessible rating display.

## Tags

Use semantic chips.

## Timeline

Use candidate/application timeline in detail drawer.

## Interview

Schedule and view interviews.

## Offer

Create and view offers.

## Responsive

Mobile uses stage tabs and candidate cards.
