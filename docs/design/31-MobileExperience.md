# 31 - Mobile Experience

## Goal

Define mobile design rules for all Jobs View surfaces.

## Bottom Navigation

Use for high-frequency candidate routes and app portals where useful. Keep to 4-5 primary items.

## Drawer

Use drawer for full navigation, filters, and secondary actions.

## Touch Targets

Minimum 44px. Important actions should be easy to tap.

## Responsive Rules

Single-column content, stacked cards, sticky primary actions, responsive tables, full-width forms.

## Mobile Gestures

Use standard gestures only. Do not rely on hidden gestures for critical actions.

## Prompt For Stitch

Read `00-DesignSystem.md` then apply these mobile rules to the requested section.
